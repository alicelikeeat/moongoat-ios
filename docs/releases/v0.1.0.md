MoonGoat 首个 iOS 预览版：离线层叠三消游戏与原生 SwiftUI 界面。

### 游戏与界面

- 三层遮挡、七格收集槽、三张同类消除；36 / 48 / 60 张牌难度。
- 撤回、洗牌、提示、胜负反馈和本地存档。
- iOS 26 原生 Liquid Glass；较早系统使用材质回退。
- 浮动气泡、飞牌、消除动效与触感反馈。
- 三套牌面主题，支持从系统照片选择器替换自定义牌面；图片仅在设备内处理。

### 下载与安装

下载附件 **MoonGoat-unsigned.ipa**。这是 arm64 iPhoneOS 未签名包，最低 iOS 17，普通 iPhone 安装前需要用自己的证书签名。原生 Liquid Glass 需要 iOS 26。

校验：将 IPA 与 `.sha256` 放在同一目录，运行 `shasum -a 256 -c MoonGoat-unsigned.ipa.sha256`。

SHA-256：`1f1671832b059b5a05adcf6a4d50ab9eb167abc72a3b9246310edf9472b0988a`
