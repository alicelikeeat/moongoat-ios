MoonGoat v0.1.3 预览版：针对点击与消除时卡顿的性能优化。

### 点击和消除优化

- 预计算牌局遮挡关系，只在牌局内容变化时生成棋盘快照；合并阶段不再逐张扫描整盘。
- 棋盘与单牌使用独立可比较视图，减少无关状态更新造成的重建。
- 只为可操作牌启用飞牌几何；完全被同位置上层牌盖住的牌不参与绘制，揭开时恢复。
- 去除密集牌堆逐牌模糊阴影，保留实体侧边；消除合并期间暂停背景气泡漂移。
- 消除输入锁定约 770ms → 410ms，保留原生玻璃合并与撤回分离。
- 自定义牌面预解码，避免在飞牌时首次解码图片。

### 存档与兼容

存档 JSON 编码与原子写入移至独立 actor，避免每次点击在主线程写盘。异步写入按递增版本处理，过时快照不能覆盖新进度；进入后台时申请短暂时间等待保存。

108/240/360 张牌、20 类牌面和旧存档保持兼容。**安装更新后可继续原来的牌局，无需重新开局。**

### 验证与边界

Xcode 26.6 arm64 iPhoneOS Release 编译通过，20 项测试通过，包括遮挡缓存逐步对照、揭露恢复、并发保存顺序与失败重试。

固定 Seed 2026 的 360 张测试局：保留绘制牌 187 张，飞牌几何候选 33 张。附件 benchmark.json 为 macOS CPU 微基准，不代表真实 iPhone 的帧率或总体提速比例。手机上的点击手感与帧时间仍需设备验证。
