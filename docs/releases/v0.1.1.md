MoonGoat v0.1.1 预览版：iOS 原生玻璃气泡、合并与分离动效。

### 新增动效

- iOS 26 原生 `GlassEffectContainer`、`glassEffectID`、`glassEffectUnion` 与形状变换。
- 背景使用原生玻璃圆形气泡；靠近时由系统融合，远离时分离。
- 三张消除按“飞入槽 → 收拢合并 → 消散”播放；撤回按反方向分离并回到棋盘。
- 工具栏可展开和收起，配合原生玻璃形变、交互高光、符号替换与弹簧反馈。
- 减少动态效果时跳过合并/分离并暂停漂浮；降低透明度使用不透明背景。

### 一致性与验证

- 规则与存档即时完成，临时动画帧不写入存档；动画期间防止重复操作。
- 开始新局、退到后台或改变减少动态效果设置时取消过渡，恢复完整状态。
- 存档格式不变，兼容 v0.1.0 的牌局。
- Xcode 26.6 arm64 iPhoneOS Release 编译通过，11 项自动化测试通过。
